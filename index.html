사용자 매뉴얼

조직 안에서 안전하게 쓰는 Internal AI iStation

iStation 사용자 매뉴얼은 화면 구성부터 AI 대화, 자료 관리, Agent 활용까지 실제 업무 흐름에 따라 안내합니다. 화면 이미지와 단계별 설명을 제공해 처음 사용하는 사용자도 주요 기능을 쉽게 따라 할 수 있습니다. 서비스 기능이 업데이트되면 변경 사항에 맞춰 매뉴얼도 함께 개정됩니다.

서비스 목적과 접속 흐름.

iStation은 사내 데이터를 외부로 노출하지 않는 Sovereign AI 구조를 기반으로, 여러 LLM과 사내 문서 검색, 특화 Agent를 한곳에서 활용하도록 만든 통합 AI 업무 플랫폼입니다. 처음 사용하는 경우 서비스 목적, 접속 환경, 화면의 세 영역을 순서대로 이해하면 이후 기능을 훨씬 수월하게 따라갈 수 있습니다.

iStation 소개

iStation은 다양한 LLM을 사내 환경에서 안전하게 활용할 수 있도록 설계된 업무용 AI 플랫폼입니다. 일반 대화, 문서 검색, 이미지와 영상 생성, 문서 작성까지 업무 흐름에 필요한 AI 기능을 한곳에서 사용할 수 있습니다. 처음에는 전체 구조를 파악한 뒤 자주 쓰는 기능부터 익히면 도입 부담을 줄일 수 있습니다.

  1. 사내 데이터 보안 민감 정보와 내부 문서가 외부 서버로 유출되지 않도록 통제된 환경에서 AI를 사용합니다.
  2. 업무 생산성 향상 Anthropic, OpenAI, Google 등 다양한 모델을 목적에 맞게 선택해 활용합니다.
  3. 맞춤형 지식 활용 사내 문서를 업로드하고 RAG 검색을 켜면 내부 자료 기반의 업무 답변을 받을 수 있습니다.

전체 기능 링크 인덱스

아래 표에서 iStation 매뉴얼의 주요 기능을 한눈에 확인하고 필요한 항목으로 바로 이동할 수 있습니다.

권장 환경과 로그인지원 브라우저, 사내망 접속, 계정 권한과 최초 로그인 흐름을 확인합니다. 화면 기본 구성좌측 사이드바, 중앙 대화 영역, 우측 자료 패널의 역할을 이해합니다. 토큰 사용량 확인이번 질의, 누적 통계, 잔여 토큰을 확인하는 방법을 안내합니다. 새 그룹 AI 만들기자료와 멤버를 함께 관리하는 그룹 공간을 생성합니다. 새 채팅 시작하기주제별 대화를 분리해 기록하고 다시 찾아볼 수 있게 합니다. LLM 모델 선택Tilon LLM과 Public AI 중 업무 목적에 맞는 모델을 선택합니다. 웹 검색 / 문서 검색최신 외부 정보와 업로드 문서 중 답변에 참고할 범위를 설정합니다. 메시지 작성 및 전송질문을 입력하고 답변을 생성한 뒤 복사해 업무 문서에 활용합니다. 파일 첨부하기대화 중 문서나 이미지를 일회성으로 첨부해 분석을 요청합니다. 프롬프트 작성 가이드목적, 맥락, 형식, 역할을 명확히 적어 답변 품질을 높입니다. 문서 업로드그룹 자료 패널에 업무 문서를 등록해 AI 답변의 근거로 활용합니다. 학습 상태 확인업로드 문서의 임베딩 처리 상태와 실패 시 조치 방법을 확인합니다. 이미지 생성하기텍스트 프롬프트와 옵션으로 업무용 이미지를 생성합니다. 비디오 생성하기장면, 움직임, 카메라 워크, 재생 시간을 지정해 영상을 생성합니다. 문서 작성하기보고서, 기획서, 회의록 등 업무 문서 초안을 생성하고 다듬습니다. 대화 내역 삭제개별 대화 또는 전체 대화 기록을 삭제할 때 주의할 점을 확인합니다. 데이터 보안내부 자료, 그룹 권한, Public AI 사용 시 보안 원칙을 안내합니다. 입력 금지 사항고객 정보, 미공개 자료 등 외부 전달을 피해야 할 내용을 정리합니다. FAQ와 오류 대처비밀번호, 토큰 한도, 응답 지연, 파일 업로드 실패 상황을 해결합니다. 기술 지원 문의오류 화면과 재현 조건을 정리해 지원 담당자에게 전달합니다.

권장 환경과 로그인

원활한 사용을 위해 지원 브라우저와 사내 접속 환경을 먼저 확인합니다. 로그인 오류나 화면 표시 문제는 대부분 브라우저 버전, 네트워크 상태, 계정 권한과 관련되어 있으므로 최초 접속 전에 기본 환경을 점검하는 것이 좋습니다. 사내망 밖에서 접속해야 하는 경우에는 VPN 연결 상태도 함께 확인합니다.

  1. 지원 브라우저 Chrome 또는 Edge 최신 버전을 권장하며 Internet Explorer는 지원하지 않습니다.
  2. 접속 환경 사내망 접속을 기본으로 하며, VPN 사용 시 별도 안내에 따라 접속합니다.
  3. 계정과 권한 IT 관리팀 또는 그룹 관리자에게 계정 생성을 요청하고, 부서와 직무에 맞는 권한을 부여받습니다.
  4. 최초 로그인 TOT 인증을 거쳐 로그인한 뒤 최초 접속 시 필요한 계정 설정을 완료합니다.

시스템 권장 사양

  • 브라우저 최신 버전 브라우저 환경에서 정상 동작합니다.
  • 화면 해상도 UI는 1920×1080 해상도 기준으로 설계되어 있습니다.
  • 접속 환경 안정적인 사내망 또는 VPN 연결 상태에서 사용하는 것을 권장합니다.

화면 기본 구성

iStation 화면은 좌측 사이드바, 중앙 대화 영역, 우측 자료 패널로 구성됩니다. 좌측에서는 대화와 Agent 기능을 이동하고, 중앙에서는 질문과 답변을 주고받으며, 우측에서는 그룹 자료를 관리합니다. 세 영역의 역할을 먼저 이해하면 이후 문서 검색이나 Agent 활용도 훨씬 자연스럽게 이어집니다.

  1. 좌측 사이드바 새 채팅, 새 그룹 AI, 이미지 생성, 비디오 생성 등 주요 기능으로 이동합니다. 현재 계정의 토큰 사용량도 확인할 수 있습니다.
  2. 중앙 대화 영역 사용할 AI 모델을 선택하고 웹 검색 또는 문서 검색 옵션을 켠 뒤 질문을 입력합니다.
  3. 우측 자료 패널 그룹별 문서를 업로드하고 임베딩, 즉 학습 처리 상태를 확인합니다.

토큰 사용량 확인

좌측 하단의 토큰 패널에서 현재 질문과 답변에 사용된 토큰, 누적 토큰, 남은 토큰을 확인합니다. 토큰은 AI가 입력을 읽고 답변을 생성할 때 사용하는 사용량 단위입니다. 긴 문서 분석이나 반복 생성 작업을 할 때는 남은 토큰을 확인해 업무 중간에 사용 한도에 걸리지 않도록 관리합니다.

  1. 이번 질의 사용자가 입력한 질문과 AI 답변 생성에 쓰인 토큰 수를 보여줍니다.
  2. 누적 통계 지금까지 사용한 입력 토큰과 출력 토큰의 합계를 확인합니다.
  3. 잔여 토큰 배정된 전체 토큰 한도 대비 현재 사용할 수 있는 토큰을 수치와 상태로 표시합니다.

대화를 목적에 맞는 공간에서.

iStation의 대화는 단순히 질문을 입력하는 방식이 아니라, 그룹과 채팅의 단위를 선택해 맥락을 관리하는 방식입니다. 관련 자료와 사용자를 함께 묶어야 할 때는 그룹 AI를 만들고, 주제가 바뀌거나 별도 기록이 필요할 때는 새 채팅을 시작합니다. 이후 모델과 검색 범위를 정하면 답변이 참고할 기준도 명확해집니다.

새 그룹 AI 만들기

그룹은 관련 자료와 대화를 하나로 묶어 관리하는 단위입니다. 프로젝트, 부서, 업무 주제별로 그룹을 만들면 필요한 문서와 대화 기록을 한 공간에서 이어갈 수 있습니다. 여러 사람이 같은 자료를 기반으로 답변을 받아야 할 때는 개인 채팅보다 그룹 AI를 사용하는 것이 적합합니다.

  1. 좌측 상단 메뉴에서 새 그룹 AI를 선택합니다.
  2. 주제를 알아보기 쉬운 그룹 이름과 간단한 설명을 입력합니다.
  3. 개인용으로 쓸지, 다른 사용자와 공유할지 공개 여부를 설정합니다.
  4. 그룹 생성 / 멤버 초대 제한 현재 별도 제한은 없으며, 정책 수립 후 반영 예정입니다.
  5. 공유 그룹이라면 함께 사용할 멤버를 검색해 초대합니다.
  6. 권한 설정 매니저는 그룹 설정과 멤버 관리를, 업로더는 자료 업로드와 조회를, 뷰어는 대화 참여와 자료 조회를 할 수 있습니다.
  7. 생성 버튼을 누르면 좌측 그룹 목록에 새 그룹이 추가되고, 그룹 자료는 멤버에게 동기화됩니다.

새 채팅 시작하기

주제가 바뀌면 새 채팅을 만들어 이전 맥락과 섞이지 않게 대화합니다. 하나의 채팅 안에 여러 업무를 섞으면 AI가 이전 대화 내용을 잘못 참고할 수 있으므로, 보고서 작성, 자료 요약, 아이디어 도출처럼 목적이 다른 작업은 분리하는 것이 좋습니다. 새 채팅을 활용하면 나중에 기록을 다시 찾기도 쉬워집니다.

  1. 좌측 메뉴에서 새 채팅을 선택합니다.
  2. 중앙 화면에 새 대화창이 열리면 원하는 질문을 입력합니다.
  3. 진행한 대화는 좌측 채팅 목록에 자동 저장되어 나중에 다시 확인할 수 있습니다.

LLM 모델 선택

대화 화면 상단의 두 드롭다운에서 모델 유형과 세부 모델을 선택합니다. 모델마다 강점이 다르므로 민감한 내부 정보, 긴 문서 분석, 일반 아이디어 발상처럼 목적에 따라 적절한 모델을 고르는 것이 중요합니다. 중요한 작업은 중간에 모델을 자주 바꾸기보다 같은 모델로 이어가면 답변 톤과 판단 기준을 안정적으로 유지할 수 있습니다.

  1. 모델 유형 선택 첫 번째 드롭다운에서 Tilon LLM 또는 Public AI를 선택합니다.
  2. 세부 모델 선택 두 번째 드롭다운에서 Claude, GPT, Gemini 등 제공사별 모델을 선택합니다.
  3. Tilon LLM 민감한 내부 정보가 포함된 질문에 권장되는 사내 전용 AI 모델입니다.
  4. Public LLM 일반 지식, 최신 정보 탐색, 초안 작성과 아이디어 기획에 활용할 수 있는 공개 모델입니다.
  5. 모델 유지 중요한 문서 작업은 답변 스타일이 흔들리지 않도록 처음부터 끝까지 같은 모델로 진행하는 것을 권장합니다.

웹 검색과 문서 검색 설정

상단 우측의 토글로 답변이 참고할 정보 범위를 선택합니다. 최신 외부 정보가 필요하면 웹 검색을, 업로드한 내부 자료를 근거로 답변받고 싶으면 문서 검색을 활용합니다. 두 옵션을 어떻게 조합하느냐에 따라 답변의 근거와 범위가 달라지므로 질문 목적에 맞게 설정합니다.

  1. 웹 검색과 문서 검색 모두 켜기 최신 외부 정보와 업로드한 내부 문서를 함께 참고합니다.
  2. 웹 검색만 켜기 내부 문서는 제외하고 외부 웹 정보 기반으로 답변합니다.
  3. 문서 검색만 켜기 웹 검색 없이 사용자가 업로드한 내부 문서만 기반으로 답변합니다.
  4. 주의 정확한 답변 생성을 위해 웹 검색 또는 문서 검색 중 최소 하나는 켜져 있어야 합니다.

메시지 작성 및 전송

화면 하단 입력창에 질문이나 요청사항을 작성한 뒤 전송합니다. 단순 질문뿐 아니라 요약, 번역, 비교, 초안 작성, 표 정리처럼 원하는 작업 형태를 함께 적으면 바로 활용하기 좋은 답변을 받을 수 있습니다. 답변이 생성된 뒤에는 복사 기능을 사용해 메일, 보고서, 메신저 등에 빠르게 옮길 수 있습니다.

  1. 입력창에 원하는 질문을 작성합니다. Enter로 전송하고 Shift + Enter로 줄바꿈할 수 있습니다.
  2. 전송 버튼을 누르면 AI가 답변을 생성하고 현재 채팅 기록에 저장합니다.
  3. 받은 답변 하단의 답변 복사 버튼을 사용하면 결과를 다른 문서에 손쉽게 옮길 수 있습니다.

파일 첨부하기

대화 중 참고할 문서나 이미지를 일회성으로 바로 첨부해 분석을 요청할 수 있습니다. 회의 자료, 화면 캡처, 표 파일처럼 특정 질문에만 필요한 자료를 빠르게 확인할 때 유용합니다. 반복적으로 참고해야 하는 문서는 파일 첨부보다 그룹 자료로 등록해 문서 검색과 함께 사용하는 편이 효율적입니다.

  1. 입력창 좌측의 파일 첨부 아이콘을 클릭합니다.
  2. 참고할 문서 또는 이미지 파일을 선택해 첨부합니다.
  3. 질문과 함께 파일을 전송하면 AI가 첨부 내용을 참고해 답변합니다.
  4. 여러 번 반복해서 사용할 자료라면 파일 첨부보다 그룹 자료로 등록하는 방식이 더 편리합니다.

효과적인 프롬프트 작성

질문의 목적과 형식을 구체적으로 전달할수록 바로 활용하기 좋은 답변을 받을 수 있습니다. AI는 사용자가 제공한 맥락과 조건을 기준으로 답변을 구성하므로, 원하는 결과물의 용도와 독자, 분량, 형식을 함께 알려주는 것이 중요합니다. 처음부터 완벽한 질문을 만들기보다 결과를 보며 후속 요청으로 다듬는 방식도 효과적입니다.

  1. 목적 명시 요약, 비교, 초안 작성, 검토처럼 원하는 작업을 분명하게 적습니다.
  2. 맥락 제공 어떤 업무에 사용할 답변인지, 대상 독자가 누구인지 함께 알려줍니다.
  3. 형식 지정 표, 목록, 단계별 설명, 3줄 요약처럼 원하는 출력 형태와 분량을 요청합니다.
  4. 역할 부여 보고서 검토자, 신입 교육 담당자처럼 AI가 취할 관점을 지정합니다.
  5. 이어가기 결과가 부족하면 새 질문을 만들기보다 “이 부분을 더 구체적으로”처럼 후속 요청으로 다듬습니다.

내 자료를 바탕으로 정확하게.

문서 검색을 활용하려면 AI가 참고할 자료를 그룹에 업로드해야 합니다. 업로드된 자료는 임베딩, 즉 AI가 검색 가능한 형태로 색인하는 과정을 거치며, 완료 상태가 되어야 답변 생성에 안정적으로 활용됩니다. 실패 상태가 보이면 파일 형식과 용량을 확인한 뒤 다시 업로드합니다.

문서 업로드

우측 그룹 자료 패널에서 AI 답변에 사용할 문서를 등록합니다. 업로드한 문서는 그룹 단위로 관리되며, 문서 검색을 켰을 때 AI가 답변 근거로 참고할 수 있습니다. 프로젝트 자료, 매뉴얼, 회의록처럼 반복적으로 확인해야 하는 파일을 등록해두면 매번 첨부하지 않아도 일관된 답변을 받을 수 있습니다.

  1. 우측 패널의 문서 업로드 영역을 선택합니다.
  2. 지원 파일 확장자 현재 pdf, doc, docx, pptx, csv, xls, xlsx, txt, md, html, json, jsonl 총 12개 확장자를 지원합니다.
  3. 파일을 드래그하거나 클릭해 보고서, 회의록, 기획서, 데이터표, 발표 자료 등을 등록합니다.
  4. 파일당 최대 업로드 용량 채팅 중 파일 업로드는 50MB/1개 파일, 공유 폴더 파일 업로드는 5GB/1개 파일까지 지원합니다.
  5. 파일명 규칙 현재 한글과 특수문자에 대한 별도 제한은 없으며, 파일명 길이가 100자 미만인 경우에만 저장 가능합니다. 추후 정규식 검증 로직이 추가될 예정입니다.
  6. 그룹 전체 저장 용량 한도 추후 공유 예정입니다.
  7. 업로드한 자료를 답변에 활용하려면 대화 상단의 문서 검색 토글을 켭니다.

학습 상태 확인

문서가 AI가 검색할 수 있는 형태로 처리되고 있는지 상태를 확인합니다. 업로드 직후에는 파일이 바로 답변에 활용되지 않을 수 있으며, 임베딩 처리가 완료되어야 문서 검색에서 안정적으로 검색됩니다. 실패 상태가 보이면 파일 형식, 용량, 내용 구조를 확인한 뒤 다시 업로드하거나 관리자에게 문의합니다.

  1. 상태 탭 확인 전체, 업로드, 임베딩 완료, 실패 등 진행 상태를 살펴봅니다.
  2. 임베딩 의미 AI가 문서를 이해하고 검색 가능한 형태로 색인하는 과정입니다.
  3. RAG 수용 가능 파일 용량 현재 100MB/1개 파일까지 수용 가능하며, 2GB 파일도 인덱싱되도록 수정 예정입니다. 변경 시 재공유됩니다.
  4. RAG 요청 문서 목록의 RAG 요청 버튼으로 색인을 요청하고 완료 상태가 될 때까지 기다립니다.
  5. 공유 폴더 RAG 권한 권한별로 출력되는 버튼이 다르며, RAG 요청 후 관리자, 방장, 매니저 권한 사용자가 승인하면 AI 서버에 인덱싱 작업을 요청합니다.
  6. 새로고침 우측 상단 새로고침으로 최신 처리 상태를 확인합니다.
  7. 파일 삭제 업로드 파일을 마우스 우클릭한 뒤 메뉴에서 파일 삭제를 선택하면 해당 파일이 삭제됩니다.
  8. 실패 시 조치 파일 형식과 용량을 확인한 뒤 다시 업로드합니다.

이미지, 영상, 문서까지 Agent 하나로 손쉽게.

Station의 Agent는 단순 질의응답을 넘어, 이미지·비디오·문서 생성처럼 결과물의 목적이 명확한 작업을 전담하는 기능입니다. 좌측 사이드바의 Agent 메뉴에서 원하는 생성 기능으로 이동한 뒤, 대상과 분위기, 스타일, 구도 같은 조건을 프롬프트로 구체화하고 모델·옵션을 함께 지정하면 완성도 높은 결과물을 얻을 수 있습니다. 원하는 결과가 한 번에 나오지 않을 경우, 조건을 조정해 다시 요청하는 방식으로 결과물을 다듬어갑니다.

이미지 생성하기

좌측 Agent 메뉴에서 텍스트 설명만으로 이미지를 생성합니다. 업무 문서, 발표 자료, 게시물에 사용할 시각 자료를 빠르게 만들 수 있으며, 원하는 스타일과 분위기를 프롬프트로 직접 지정할 수 있습니다. 결과물의 완성도는 대상, 배경, 색상, 구도처럼 시각 요소를 얼마나 구체적으로 설명하는지에 따라 달라집니다.

  1. 좌측 사이드바의 Agent 메뉴에서 Image Generation을 선택합니다.
  2. 이미지를 생성할 AI 모델을 지정합니다.
  3. 게시글, 갤러리, 목록 중 결과물 표시 방식을 선택합니다.
  4. 생성 개수 등 이미지 옵션을 설정합니다.
  5. 대상, 분위기, 배경, 스타일을 프롬프트로 구체적으로 입력하고 생성을 요청합니다.

이미지 프롬프트 작성 가이드

효과적인 이미지 생성을 위해서는 원하는 결과물을 구체적인 요소로 나누어 전달하는 것이 중요합니다.

  1. 주제(Subject) 명시 무엇을 그릴지 핵심 대상을 가장 먼저 명확히 적습니다. 예: 노트북 앞에 앉은 여성 개발자
  2. 스타일 지정 사진, 일러스트, 3D 렌더링, 수채화, 미니멀 벡터 등 원하는 화풍을 지정하면 결과물의 일관성이 높아집니다.
  3. 구도와 앵글 클로즈업, 전신샷, 정면, 측면, 부감처럼 카메라 시점을 함께 요청합니다.
  4. 배경과 분위기 실내와 야외, 밝은 톤과 어두운 톤, 미니멀한 배경과 디테일한 배경처럼 장면의 맥락을 설명합니다.
  5. 색상 팔레트 브랜드 컬러나 원하는 주조색을 지정하면 사내 문서와 발표 자료의 톤을 맞추기 쉽습니다.
  6. 디테일 순서로 작성 대상 → 행동/포즈 → 배경 → 스타일 → 분위기 순으로 문장을 구성하면 AI가 우선순위를 더 잘 인식합니다.
  7. 제외할 요소 명시 원하지 않는 텍스트, 로고, 특정 색상 등이 있다면 “텍스트는 제외”처럼 함께 적습니다.
  8. 참고 이미지 활용 비슷한 스타일의 참고 이미지가 있다면 함께 첨부해 원하는 톤을 더 정확히 전달할 수 있습니다.
  9. 반복 개선 한 번에 완성하려 하지 말고, 생성된 결과를 보며 “배경을 더 밝게”, “인물을 더 크게”처럼 부분 수정 요청으로 다듬습니다.

비디오 생성하기

비디오 생성 화면에서 모델과 보기 방식을 선택한 뒤 원하는 영상 프롬프트를 전송합니다. 짧은 홍보 영상, 콘셉트 시안, 발표용 장면 예시처럼 움직임이 필요한 결과물을 만들 때 활용할 수 있습니다. 영상은 장면 전환과 카메라 움직임이 포함되므로 이미지보다 더 구조적으로 조건을 작성하는 것이 좋습니다.

  1. 좌측 사이드바의 Agent 메뉴에서 Video Generation을 선택합니다.
  2. 영상을 만들 AI 모델을 지정합니다.
  3. 게시글, 갤러리, 목록 중 결과물 표시 방식을 선택합니다.
  4. 영상 재생 시간 등 옵션을 설정합니다.
  5. 하단 프롬프트 입력창에 원하는 영상 내용을 작성하고 전송합니다.
  6. 영상 생성은 이미지보다 오래 걸릴 수 있으니 완료될 때까지 진행 상태를 확인합니다.

비디오 프롬프트 작성 가이드

영상은 이미지보다 담아야 할 정보가 많으므로 움직임, 시간 흐름, 카메라 워크를 구조적으로 작성할수록 결과물 품질이 올라갑니다.

  1. 장면(Scene) 설명 어떤 장소, 어떤 상황인지 배경을 먼저 설명합니다. 예: 사무실 회의실에서 발표하는 장면
  2. 주요 동작/움직임 인물이나 사물이 어떻게 움직이는지 구체적으로 작성합니다. 예: 발표자가 화면을 가리키며 걸어 나오는 동작
  3. 카메라 워크 지정 고정샷, 줌인/줌아웃, 패닝, 트래킹처럼 카메라 움직임을 요청하면 훨씬 영상다운 결과가 나옵니다.
  4. 시간 흐름 표현 짧은 영상이라도 시작 → 중간 → 끝의 변화를 넣으면 자연스러운 흐름이 생깁니다.
  5. 분위기와 톤 지정 밝고 경쾌한 느낌, 차분하고 전문적인 느낌처럼 원하는 무드를 형용사로 명시합니다.
  6. 스타일 지정 실사, 애니메이션, 모션 그래픽 등 영상의 전체 스타일을 정합니다.
  7. 재생 시간 고려 사용자가 지정한 재생 시간 안에 표현 가능한 정도로 내용을 압축해서 작성합니다. 너무 많은 사건을 한 프롬프트에 담지 않습니다.
  8. 오디오/텍스트 요소 자막, 배경음, 특정 사운드가 필요하면 별도로 명시합니다. 지원 여부는 모델별로 다를 수 있습니다.
  9. 반복 개선 결과 확인 후 “카메라를 더 천천히”, “인물 움직임을 자연스럽게”처럼 구체적 수정 요청으로 이어갑니다.

문서 작성하기

보고서, 기획서, 회의록, 이메일 등 업무 문서의 초안을 자동으로 생성하는 Agent입니다. 사용자가 입력한 주제와 조건을 바탕으로 문서 구조를 잡고, 필요한 경우 표나 목록을 포함한 형태로 결과를 정리합니다. 새 문서를 처음부터 작성할 때뿐 아니라 지금까지 나눈 대화 내용을 문서 형태로 정리할 때도 사용할 수 있습니다.

  1. 문서 목적 정하기 보고서, 기획서, 회의록, 이메일처럼 만들 문서 유형을 먼저 정합니다.
  2. 핵심 내용 입력 문서에 반드시 포함할 키워드, 배경, 대상 독자, 전체 개요를 프롬프트에 작성합니다.
  3. 형식 지정 제목 구조, 목차, 분량, 문체, 표 포함 여부 등 원하는 결과 형태를 함께 요청합니다.
  4. 결과 확인 생성된 문서를 화면에서 확인하고 빠진 내용이나 어색한 표현을 추가 요청으로 수정합니다.
  5. 내보내기 “문서 만들어 줘”, “파일 생성해줘”처럼 요청하면 LLM이 판단해 pdf, docx 파일 2개로 생성합니다. 특정 확장자가 필요하면 “pdf로 만들어줘”처럼 원하는 확장자를 프롬프트에 명시합니다.

문서 프롬프트 작성 가이드

문서 작성 Agent는 새로운 기획안을 처음부터 짜는 것뿐 아니라, 진행 중인 대화 내용을 그대로 문서로 정리하는 것도 가능합니다. 목적에 따라 프롬프트 작성 방식을 다르게 구성하면 결과물 품질이 높아집니다.

  1. 문서 유형 지정 기획안, 보고서, 회의록, 이메일 등 원하는 문서 형식을 가장 먼저 명시합니다.
  2. 핵심 조건 입력 주제, 타깃, 기간, 장소처럼 문서에 반드시 들어가야 할 정보를 구체적으로 나열합니다. 예: 포켓몬 팝업 이벤트 기획안 작성해줘. 20-30대 타깃, 성수동에서 진행
  3. 목차 구조 요청 개요, 타깃 분석, 컨셉, 예산처럼 원하는 섹션 구성이 있다면 함께 요청합니다. 지정하지 않으면 AI가 기본 구성으로 작성합니다.
  4. 표/리스트 형식 지정 타깃 인사이트, 일정처럼 비교와 정리가 필요한 내용은 “표로 정리해줘”라고 요청하면 가독성이 높아집니다.
  5. 대화 내용 기반 작성 지금까지 나눈 대화를 그대로 문서로 만들고 싶다면 “지금까지 논의한 내용을 문서로 정리해줘”처럼 요청합니다.
  6. 파일 형식 요청 완성된 결과를 “워드 파일로 보내줘”, “pdf로 만들어줘”처럼 요청하면 다운로드 가능한 형태로 받을 수 있습니다. 특정 확장자가 필요할 때는 프롬프트에 확장자를 직접 언급합니다.
  7. 결과 확인 및 수정 생성된 문서를 보고 “3번 항목 더 구체적으로”, “표 하나 추가해줘”처럼 부분 수정 요청으로 다듬습니다.

보안부터 문제 대응까지 확실하게.

iStation은 사내 데이터 보호를 전제로 설계된 서비스이지만, 사용자가 어떤 모델을 선택하고 어떤 정보를 입력하는지도 중요합니다. 민감 정보는 Tilon LLM을 우선 사용하고, Public AI에는 기밀 정보를 입력하지 않으며, 오류가 반복될 때는 화면과 상황을 정리해 관리자에게 문의합니다.

대화 내역 삭제

필요한 경우 개별 대화 또는 전체 대화 내역을 삭제할 수 있습니다. 잘못 생성된 대화, 더 이상 필요하지 않은 작업 기록, 민감한 내용이 포함된 대화는 관리 기준에 따라 정리합니다. 삭제 후에는 복구가 어려울 수 있으므로 필요한 답변은 먼저 복사하거나 별도 문서에 보관한 뒤 진행합니다.

  1. 삭제할 대화나 삭제 메뉴가 있는 위치로 이동합니다.
  2. 삭제 대상을 다시 확인한 뒤 삭제를 실행합니다.
  3. 삭제된 대화는 복구가 불가능하므로 중요한 답변은 답변 복사 기능으로 별도 보관합니다.

데이터 보안과 프라이버시

업무 자료와 대화 내용을 안전하게 다루기 위해 기본 보안 원칙을 확인합니다. iStation은 사내 데이터 보호를 전제로 설계되었지만, 어떤 모델을 선택하고 어떤 정보를 입력하는지는 사용자의 판단도 중요합니다. 내부 자료를 다룰 때는 접근 권한과 공유 범위를 확인하고, 외부 공개 모델 사용 시에는 기밀 정보 입력을 피합니다.

  1. Tilon LLM 입력 데이터가 외부로 전송되지 않으며 모델 학습에 활용되지 않는 내부 전용 모델입니다.
  2. 그룹 자료 접근 업로드된 문서는 해당 그룹 멤버에게만 접근이 허용됩니다.
  3. Public AI 주의 외부 공개 모델 사용 시 제공사 정책이 적용될 수 있으므로 사내 기밀 정보 입력을 피합니다.
  4. 권한 점검 퇴사, 부서 이동, 프로젝트 종료 시 매니저가 그룹 멤버와 권한을 정리합니다.

AI 입력 금지 사항

Public AI 사용 시에는 외부로 전달되면 안 되는 정보를 입력하지 않습니다. 고객 정보, 계약 내용, 재무 자료, 내부 전략처럼 공개되지 않은 정보는 업무 편의를 위해서라도 입력하지 않는 것이 원칙입니다. 민감 여부가 애매한 경우에는 먼저 사내 전용 모델을 사용하거나 관리자에게 확인한 뒤 진행합니다.

  1. 고객 정보 금지 이름, 연락처, 계약 정보 등 식별 가능한 고객 정보를 입력하지 않습니다.
  2. 미공개 자료 금지 재무 자료, 인사 정보, 내부 전략, 계약서 등 공개되지 않은 정보를 입력하지 않습니다.
  3. 민감 여부가 애매할 때 우선 Tilon LLM으로 질문하고 필요한 경우에만 Public AI로 전환합니다.
  4. 세션 관리 일정 시간 활동이 없으면 세션이 종료될 수 있으므로 재로그인이 필요할 수 있습니다.

FAQ와 오류 대처

서비스 이용 중 자주 발생하는 상황은 아래 기준으로 먼저 확인합니다. 로그인 문제, 응답 지연, 토큰 한도, 파일 업로드 실패처럼 반복되는 이슈는 원인을 좁혀보면 빠르게 해결할 수 있습니다. 동일한 문제가 계속되면 화면 캡처와 발생 조건을 함께 정리해 문의하면 처리 시간이 줄어듭니다.

  1. 비밀번호를 잊은 경우 로그인 화면의 비밀번호 찾기를 통해 재설정합니다.
  2. 그룹에서 나가려는 경우 그룹 설정 메뉴에서 그룹 나가기를 선택합니다.
  3. 토큰 한도를 모두 쓴 경우 부서 관리자에게 추가 크레딧 배정을 요청합니다.
  4. 응답 지연 네트워크 상태를 확인하고 페이지를 새로고침한 뒤, 지속되면 관리자에게 문의합니다.
  5. 파일 업로드 실패 지원 확장자와 용량 제한을 확인하고 다시 업로드합니다. 채팅 중 파일 업로드는 50MB/1개 파일, 공유 폴더 파일 업로드는 5GB/1개 파일 기준입니다.
  6. 오류 대처 시나리오 상세 Troubleshooting 항목은 추후 공유 예정입니다.

기술 지원 문의

문제가 반복되면 현상과 재현 조건을 정리해 기술 지원 담당자에게 전달합니다. 단순히 “안 됩니다”라고 문의하기보다 사용한 모델, 검색 옵션, 첨부 파일, 오류 메시지, 발생 시간을 함께 남기면 원인을 더 빠르게 파악할 수 있습니다. 업무 영향이 큰 장애라면 긴급도와 필요한 조치 시점도 함께 전달합니다.

  1. 화면 캡처 오류 메시지와 현재 화면을 캡처합니다.
  2. 상황 기록 사용한 모델, 검색 토글 상태, 업로드 파일 형식, 발생 시간을 함께 기록합니다.
  3. 문의 전달 사내 안내에 따라 기술 지원 또는 시스템 장애 문의처로 전달합니다.
  4. 제약 확인 입력 글자 수, 지원 언어, 동시 접속자 수 등 시스템 제약 사항은 추후 공유 예정입니다.
