SECTION 1

화면 기본 구성

화면은 좌측 사이드바, 중앙 대화 영역, 우측 자료 패널 세 개 영역으로 구성됩니다.

1. 좌측 사이드바

새 채팅/그룹 생성, 에이전트 이동, 토큰 사용량 확인을 담당합니다.

2. 중앙 대화 영역

AI 모델 및 검색 옵션을 설정하고, 프롬프트 입력과 대화를 진행합니다.

3. 우측 자료 패널

AI 학습용 맞춤형 문서를 업로드하고 데이터 처리 상태를 관리합니다.

1-2

토큰 사용량 확인

좌측 하단의 토큰 사용량 패널에서 실시간 소모량과 잔여 한도를 확인합니다.

1

이번 질의

현재 대화창에서 질문과 답변에 소모된 실시간 토큰 수를 보여줍니다.

2

누적 통계

지금까지 AI 모델을 사용하며 소모한 총 누적 토큰 합계를 확인합니다.

3

남은 토큰

계정에 부여된 전체 한도 대비 사용 가능한 잔여 토큰을 수치와 상태 표시줄로 보여줍니다.

SECTION 2 · 2-1

새 그룹 AI 만들기

관련 자료와 대화를 하나로 묶어 관리하는 단위가 그룹입니다.

  1. 새 그룹 AI 클릭좌측 상단 메뉴에서 새 그룹 AI를 선택합니다.
  2. 그룹 이름 및 설명 지정주제나 프로젝트 단위로 알아보기 쉬운 그룹명과 설명을 입력합니다.
  3. 공개 여부 설정개인 그룹으로 사용할지, 팀원과 함께 쓰는 공유 그룹으로 사용할지 결정합니다.
  4. 멤버 초대공유 그룹을 켠 경우 사내 멤버를 검색해 초대합니다.
  5. 생성 완료생성 버튼을 누르면 좌측 그룹 목록에 새로운 그룹이 추가됩니다.

그룹별로 업로드 문서와 대화가 분리되어 주제별 자료 관리가 편리합니다.

2-2

새 채팅 시작하기

1

새 채팅 클릭

좌측 메뉴의 새 채팅을 선택합니다.

2

대화 시작

안내 문구와 함께 빈 대화창이 열립니다.

3

자동 저장

진행한 대화는 좌측 채팅 목록에 자동 저장됩니다.

주제가 바뀌면 새 채팅으로 시작하는 것이 이전 맥락과 섞이지 않아 답변 품질에 좋습니다.

SECTION 3 · 3-1

LLM 모델 선택

화면 상단의 모델 선택 버튼에서 답변에 사용할 AI 모델을 변경합니다.

Tilon LLM

사내 보안이 중요한 업무나 회사 내부 데이터를 다룰 때 선택하는 내부 전용 모델입니다.

Public AI

일반 웹 검색, 아이디어 기획처럼 폭넓고 창의적인 답변이 필요할 때 선택하는 외부 공개 모델입니다.

민감 정보가 포함된 질문은 Tilon LLM, 일반 정보 탐색은 Public AI를 권장합니다.

3-2

웹 검색 · 문서 검색

상단 우측 두 개의 토글로 답변에 참고할 정보 범위를 조절합니다.

동시 켜기웹 최신 정보와 업로드한 사내 문서를 모두 참고합니다.
웹 검색만 켜기사내 문서를 제외하고 외부 웹 정보와 일반 지식을 사용합니다.
문서 검색만 켜기외부 검색 없이 업로드한 사내 문서 기반으로 답변합니다.
동시 꺼짐 불가정확한 AI 답변 생성을 위해 최소 하나는 반드시 켜져 있어야 합니다.
SECTION 4 · 4-1

메시지 작성 및 전송

화면 하단 입력창에 원하는 질문을 작성하고 전송합니다.

올해 업로드한 정책 문서의 핵심 변경사항을 요약해줘.
문서 검색을 기준으로 주요 변경사항과 적용 시점을 정리했습니다.

질문을 구체적으로 작성할수록 더 정확하고 유용한 답변을 얻을 수 있습니다.

4-2

파일 첨부

  1. 클립 아이콘 클릭입력창 좌측의 클립 아이콘을 클릭합니다.
  2. 파일 선택참고할 문서나 이미지 파일을 선택해 첨부합니다.

여러 문서를 반복 활용한다면 파일 첨부 대신 그룹 자료로 등록해 두면 편리합니다.

SECTION 5 · 5-1

문서 업로드

우측 그룹 자료 패널에서 AI 답변에 활용할 문서를 등록합니다.

업로드전체완료

policy.pdf공유됨

문서 검색 토글을 켜야 업로드한 자료가 실제 답변에 활용됩니다.

5-2

임베딩(학습) 상태 확인

상태 탭 확인전체, 업로드, 임베딩, 완료, 실패 탭으로 진행 상태를 확인합니다.
임베딩 = 학습(색인)AI가 문서를 이해하고 검색 가능한 형태로 색인하는 과정입니다.
새로고침으로 갱신우측 상단 새로고침으로 최신 처리 상태를 확인합니다.

실패로 표시되면 파일 형식과 용량을 확인한 뒤 다시 업로드해 주세요.

SECTION 6 · 6-1

이미지 생성 에이전트

좌측 Agent 메뉴에서 텍스트 설명만으로 이미지를 생성합니다.

1메뉴 이동

이미지 생성 전용 화면으로 진입합니다.

2모델 선택

이미지를 만들 AI 모델을 지정합니다.

3보기 방식

결과물 표시 형태를 변경합니다.

4이미지 옵션

생성 개수 같은 세부 조건을 설정합니다.

5프롬프트 입력

원하는 이미지 내용을 입력하고 생성을 요청합니다.

6-2

비디오 생성 에이전트

1메뉴 이동

비디오 생성 전용 화면으로 진입합니다.

2모델 선택

비디오를 만들 AI 모델을 지정합니다.

3보기 방식

결과물 표시 형태를 변경합니다.

4영상 옵션

영상 재생 시간 등 세부 조건을 설정합니다.

5프롬프트 입력

원하는 영상 내용을 입력하고 생성을 요청합니다.
