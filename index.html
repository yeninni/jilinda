과개교합에 대해서 말해줘

과개교합은 위 앞니가 아래 앞니를 정상보다 많이 덮는 부정교합을 말합니다. 위 앞니가 아래 앞니의 1/3~1/4 정도를 덮어야 정상인데, 이보다 깊게 덮이면 과개교합으로 볼 수 있습니다.

주요 특징 및 증상

잇몸이 많이 보임: 웃을 때 잇몸이 과도하게 드러납니다. 턱관절 통증: 깊게 물리는 치아 때문에 턱관절에 부담이 생길 수 있습니다.

원인

선천적 요인: 윗턱과 아래턱 위치 불균형, 유전적인 골격성 부정교합 등이 원인이 될 수 있습니다.

치료 방법

교정 장치: 치아 이동과 앞니 높이 조절을 통해 정상적인 교합 회복을 돕습니다.

SECTION 1

화면 기본 구성

화면은 좌측 사이드바, 중앙 대화 영역, 우측 자료 패널 세 개 영역으로 구성됩니다.

1. 좌측 사이드바

새 채팅이나 새 그룹 AI를 생성하고, 이미지 및 비디오 생성과 같은 특화 에이전트(Agent) 기능으로 이동할 수 있는 내비게이션 영역입니다. 또한, 현재 계정의 토큰(Token) 사용량을 실시간으로 모니터링할 수 있습니다.

2. 중앙 대화 영역

대화에 사용할 AI 모델을 선택하고 웹/문서 검색 옵션을 켜거나 끌 수 있습니다. 프롬프트(질문)를 입력하여 본격적인 대화가 진행되는 핵심 공간입니다

3. 우측 자료 패널

AI 학습에 필요한 맞춤형 사내 문서를 직접 업로드하고, 데이터의 임베딩(학습) 처리 상태를 실시간으로 관리하는 공간입니다

1-2

토큰 사용량 확인

좌측 하단의 토큰 사용량 패널에서 실시간 소모량과 잔여 한도를 확인합니다.

1

이번 질의

현재 진행 중인 대화창에서 사용자가 방금 입력한 질문과 AI가 작성한 답변에 소모된 실시간 토큰 수를 보여줍니다

2

누적 통계

지금까지 AI 모델을 사용하면서 소모한 총 입력 토큰과 총 출력 토큰의 누적 합계를 확인할 수 있습니다.

3

남은 토큰

내 계정에 부여된 전체 토큰 한도 대비 현재 사용 가능한 잔여 토큰을 수치 및 직관적인 상태 표시줄 형태로 안내합니다.

SECTION 2 · 2-1

새 그룹 AI 만들기

관련 자료와 대화를 하나로 묶어 관리하는 단위가 그룹입니다.

  1. 새 그룹 AI 클릭좌측 상단 메뉴에서 새 그룹 AI를 선택합니다.
  2. 그룹 이름 및 설명 지정해당 주제나 프로젝트를 알아보기 쉽게 직관적인 그룹명과 간단한 설명을 입력합니다.
  3. 공개 여부 설정해당 그룹을 혼자 독립적으로 사용할지(개인), 다른 팀원들과 함께 사용할지(공유) 결정하는 토글 버튼을 설정합니다.
  4. 멤버 초대토글을 켜서 '공유 그룹'으로 설정할 경우, 함께 자료를 보고 대화할 사내 멤버의 이름을 검색하여 초대할 수 있습니다.
  5. 생성 완료생성 버튼을 누르면 좌측 그룹 목록에 새로운 그룹이 추가됩니다.

그룹별로 업로드 문서와 대화가 분리되어 주제별 자료 관리가 편리합니다.

2-2

새 채팅 시작하기

1

시작 방법

좌측 메뉴에서 '새 채팅'을 선택하면, 중앙 화면에 "안녕하세요! 무엇이든 물어보세요"라는 안내 문구와 함께 새로운 대화창이 열립니다.

2

자동 저장

진행한 모든 대화는 좌측 '채팅' 목록에 자동으로 저장되므로 언제든 지난 대화 기록을 다시 확인할 수 있습니다.

주제가 바뀌면 새 채팅으로 시작하는 것이 이전 맥락과 섞이지 않아 답변 품질에 좋습니다.

SECTION 3 · 3-1

LLM 모델 선택

화면 상단의 모델 선택 버튼에서 답변에 사용할 AI 모델을 변경합니다.

1

모델 메뉴 열기

상단의 모델 선택 영역을 클릭해 현재 사용할 수 있는 AI 모델 목록을 확인합니다.

2

업무에 맞게 선택

사내 자료나 보안이 중요한 질문은 내부 모델을, 일반 정보 탐색은 공개 모델을 선택합니다.

3

답변 생성 확인

선택한 모델명이 상단에 표시된 상태에서 질문을 입력하면 해당 모델 기준으로 답변이 생성됩니다.

3-2

웹 검색 / 문서 검색

상단 우측 두 개의 토글로 답변에 참고할 정보 범위를 조절합니다.

동시 켜기웹 최신 정보와 업로드한 사내 문서를 모두 참고합니다.
웹 검색만 켜기사내 문서를 제외하고 외부 웹 정보와 일반 지식을 사용합니다.
문서 검색만 켜기외부 검색 없이 업로드한 사내 문서 기반으로 답변합니다.
동시 꺼짐 불가정확한 AI 답변 생성을 위해 최소 하나는 반드시 켜져 있어야 합니다.
SECTION 4 · 4-1

메시지 작성 및 전송

화면 하단 입력창에 원하는 질문을 작성하고 전송합니다.

1

질문 입력

하단 입력창에 원하는 질문이나 요청사항을 작성합니다. 필요한 경우 줄바꿈으로 내용을 구분해 입력할 수 있습니다.

2

전송 및 답변 확인

전송 버튼을 누르면 AI가 답변을 생성하며, 대화 내용은 현재 채팅 기록에 이어서 저장됩니다.

4-2

파일 첨부하기

  1. 클립 아이콘 클릭입력창 좌측의 클립 아이콘을 클릭합니다.
  2. 파일 선택참고할 문서나 이미지 파일을 선택해 첨부합니다.

여러 문서를 반복 활용한다면 파일 첨부 대신 그룹 자료로 등록해 두면 편리합니다.

SECTION 5 · 5-1

문서 업로드

우측 그룹 자료 패널에서 AI 답변에 활용할 문서를 등록합니다.

1

업로드 화면 열기

우측 그룹 자료 패널에서 문서 업로드 영역을 선택해 파일을 등록할 준비를 합니다.

2

문서 선택

AI 답변에 참고할 PDF, 문서, 이미지 등 업무 자료를 선택해 업로드합니다.

3

처리 상태 확인

업로드 후 임베딩 상태가 완료로 바뀌면 문서 검색을 통해 답변에 활용할 수 있습니다.

5-2

학습(임베딩) 상태 확인

상태 탭 확인전체, 업로드, 임베딩, 완료, 실패 탭으로 진행 상태를 확인합니다.
임베딩 = 학습(색인)AI가 문서를 이해하고 검색 가능한 형태로 색인하는 과정입니다.
새로고침으로 갱신우측 상단 새로고침으로 최신 처리 상태를 확인합니다.

실패로 표시되면 파일 형식과 용량을 확인한 뒤 다시 업로드해 주세요.

SECTION 6 · 6-1

이미지 생성하기

좌측 Agent 메뉴에서 텍스트 설명만으로 이미지를 생성합니다.

1

에이전트 선택

좌측 Agent 메뉴에서 이미지 생성 기능을 선택해 전용 생성 화면으로 이동합니다.

2

프롬프트 작성

원하는 이미지의 대상, 분위기, 배경, 스타일을 텍스트로 구체적으로 입력합니다.

3

결과 확인

생성 버튼을 누른 뒤 완성된 이미지를 확인하고, 필요하면 조건을 수정해 다시 생성합니다.

6-2

비디오 생성하기

1메뉴 이동

비디오 생성 전용 화면으로 진입합니다.

2모델 선택

비디오를 만들 AI 모델을 지정합니다.

3보기 방식

결과물 표시 형태를 변경합니다.

4영상 옵션

영상 재생 시간 등 세부 조건을 설정합니다.

5프롬프트 입력

원하는 영상 내용을 입력하고 생성을 요청합니다.
